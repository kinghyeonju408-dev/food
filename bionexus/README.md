# 바이오넥서스 — 식물 소리 연구 앱

선행연구(Khait et al., 2023, *Cell*)의 “가뭄 스트레스 토마토는 초음파 클릭음을 낸다”는 결과를
보급형 초음파 녹음기로 직접 재현하고, 우리가 녹음한 소리로 아동 체험 앱을 만든다.

- 완성 목표: **2026-10-25(일)** · 연구제출물 마감: **2026-10-28(수)**
- 실행: `bionexus/index.html`을 브라우저로 연다 (서버·설치 불필요, 데이터는 기기 밖으로 나가지 않음)
- 로컬 서버가 필요하면: 저장소 루트에서 `python3 -m http.server` → `http://localhost:8000/bionexus/`
- 테스트: `node bionexus/tests/dsp.test.js`

## 가설

- **H1** 가뭄 화분의 시간당 초음파 이벤트 수 > 대조 화분 (만-휘트니 U, 정확 검정)
- **H2** 무게 감소(%)가 클수록 이벤트 수 증가 (스피어만, 순열 검정 — 화분-일 단위이므로 탐색적)
- **H3** 재관수 후 이벤트 수 감소 (윌콕슨 부호순위, 정확 검정)
- **Q4** 공개 데이터 학습 모델을 우리 녹음에 적용했을 때 정확도 변화

## 탭별 기능

| 탭 | 내용 |
|---|---|
| 로드맵 | 위 일정 체크리스트, 지난 항목 표시 |
| 실험 기록 | 화분 등록, 매일 무게·관수 입력, 무게 변화 그래프, CSV 내보내기/불러오기 |
| 초음파 분석 | WAV(16/24/32bit, float) 분석: 4차 버터워스 고역통과 → 잡음 σ(중앙값 기반) → k·σ 초과 이벤트 검출. 분당 이벤트 그래프, 이벤트별 스펙트로그램·피크 주파수, 시간 확장 가청화(5/10/20배), 소리 라이브러리 저장. **검증용 합성 파일** 버튼으로 파이프라인 자체를 확인 |
| 통계 | 블라인드 코드 키 생성(화분×날짜), 분석 결과+무게 기록+키 통합, H1–H3 검정, 날짜별 그래프, 통합 CSV |
| 소리 체험 | 아동용: 조건 선택 → 라이브러리의 실제 녹음 재생 + 파형 |
| 청취 퀴즈 | 가뭄 vs 대조/배경 소리 2지선다, 정답률과 이항 검정 (관람객 데이터 연구 활용 시 IRB 확인 필요) |
| 떨림·반응시간 | 보조 연구: 반응시간 10회 측정, 터치 좌표 FFT로 보고 빈도·나이퀴스트 한계·주 주파수 |

## 녹음 설정 권장

- 샘플링 250–384 kHz (192 kHz 미만이면 앱이 경고), 식물에서 약 10 cm, 방음 상자 1개당 화분 1개
- 파일은 짧게 나눠 녹음 (예: 5–10분 단위) — 브라우저에서 긴 파일도 조각 단위로 읽지만 처리 시간이 늘어난다
- 블라인드: 키 보관자가 파일 이름을 코드로 바꿔 분석자에게 전달

## 데이터 보관 주의

브라우저 저장소(localStorage/IndexedDB)는 지워질 수 있다. **무게 기록·분석 결과는 매일 CSV로 내보내 공유 드라이브에 보관**할 것.
