초음파 이벤트 검출

녹음기의 WAV 파일을 넣으면 20 kHz 이상 고역통과 → 잡음 수준 추정 → 임계값 초과 지점을 이벤트로 셉니다. 파일은 서버로 올라가지 않고 이 기기에서만 처리됩니다.

파일 이름을 “코드”로 씁니다. 블라인드 판정을 할 때는 팀원이 파일 이름을 무작위 코드로 바꿔서 주세요(통계 탭에서 코드 생성). AudioMoth 기본 이름(20261007_023000.WAV)이면 녹음 시각을 자동으로 읽습니다.

1. 블라인드 코드 만들기

화분 × 날짜마다 무작위 코드를 만듭니다. 키 파일은 분석하지 않는 팀원 한 명만 보관하고, 그 사람이 녹음 파일 이름을 코드로 바꿉니다.

2. 자료 합치기

키가 없으면 파일 코드 = 화분 ID, 날짜 = 녹음 시각으로 봅니다.

야간 녹음은 정오 이전에 시작했으면 전날 밤 실험일로 셉니다.

토마토의 목소리를 들어볼까요?

식물이 내는 소리는 너무 높아서 사람 귀에는 안 들려요. 그래서 소리를 10배 느리게 틀어서 들을 수 있게 만들었어요. 헤드셋을 써 주세요.

어느 쪽이 목마른 토마토일까?

두 소리를 듣고 골라 주세요. 이름·나이 같은 개인정보는 받지 않고, 정답 여부만 셉니다.

관람객 응답을 연구 결과로 쓰려면 사전에 지도교수·학교 연구윤리(IRB) 확인이 필요합니다.

측정 도구 자체를 검증하는 화면입니다. 기준값(가속도계·슬로모션 영상)과 비교하는 절차는 로드맵의 보조 연구 항목을 따르세요.

회색 판이 초록색으로 바뀌면 바로 누르세요. 10회. 앱 기록값에는 화면·터치 지연이 섞여 있으니 240fps 영상으로 따로 보정합니다.
